# Photo Archive Manager

离线本地照片整理工具。原生八阶段窗口现已接通来源扫描、扩展名路由、安全复制、完整性校验、ExifTool 元数据检查、重复候选审核、多目标文件备份与加密 7z 分卷归档。

## 本机运行

需要 Rust 工具链：

```sh
cargo run
```

扫描只读取常规文件，不跟随符号链接；临时扫描结果保存在当前进程内存中。复制使用有界缓冲区、临时文件、SHA-256 和防覆盖提交。完整性阶段会再次读取源/目标文件；也可单独选择两个目录按相对路径核对。系统垃圾过滤可审核并可恢复包含。

阶段⑤会重新读取所选整理目录或本次复制清单中的文件，显示 GPS、原始拍摄时间、精度、时区状态、来源标签及可用相机信息。macOS arm64 与 Windows x86_64 构建均嵌入 ExifTool 13.60 和所需 Perl runtime；Windows ZIP 与释放后的 EXE 都会校验 SHA-256 和版本，并用 UTF-8 参数文件传递中文路径。macOS arm64 已在本机样本上运行验证；Windows 产物已交叉编译，但尚未在 Windows 上启动验证。macOS Intel 尚无相应有效载荷。第三方来源、许可和二进制校验值见 [`resources/exiftool/THIRD_PARTY_NOTICES.md`](resources/exiftool/THIRD_PARTY_NOTICES.md)。

阶段⑥每次重新扫描目录并重算文件 SHA-256；带可信时区的拍摄时间按逐对阈值生成候选，不做传递合并；JPEG/PNG/HEIC/HEIF 时间候选可计算 64-bit 离线 pHash，并可并排预览且应用对应格式的方向变换。HEIC/HEIF 使用内置纯 Rust 解码器，单图限制为 5000 万像素；RAW 解码仍未实现。候选只能手动标记从本次清单排除，不会删除文件。携带阶段⑥结果会生成 Final Manifest，并将已审核路径、SHA-256 和排除决定写入本机私有应用数据目录；重启后可恢复审核决定。阶段⑦/⑧来源与其重叠时，只处理清单内路径并重新核对 SHA-256。界面可清除检查点；新扫描或选择不携带时也会清除。密码和 GPS 元数据不写入检查点。当前进程内的扫描、复制、校验、元数据、重复检查、备份和归档支持安全边界暂停/恢复；暂停会在当前文件或批次等安全边界生效。关闭程序后可恢复阶段③复制计划、阶段⑦备份映射和阶段⑥审核决定；阶段⑦恢复会重新扫描来源并验证已有目标。其他阶段没有通用断点恢复，应用也不持续监视跨阶段文件改动。

阶段⑧可独立选择目录，以 GUI 双次输入密码创建 Store、AES-256、加密文件名的 7z 归档；默认每卷 2,000,000,000 字节。程序先写完整临时 7z，再按字节流切成 `.7z.001/.002/...`，逐卷限额，并在提交前重组卷流、核对完整清单及逐文件 SHA-256，最后防覆盖提交。应用内超过 2 GB 单文件测试通过；官方 7-Zip 26.05 将该两卷归档识别为 `Type = Split`，完成 `t` 与提取，解出文件和同尺寸稀疏源文件的 SHA-256 相同。分卷期间临时空间可能需要接近归档体积的两倍。密码输入由程序清空，但底层 7z 库内部密码缓冲区不保证主动擦零。窗口“开源许可”含 Rust 锁定依赖的完整许可清单；ExifTool/Perl/PAR 有效载荷单独列明。

`cargo test --locked` 最近一次为 46 passed、0 failed、3 ignored（两项需外部图片/MOV 样本；一项 2 GB 单文件压力用例需显式运行）。压力用例已用 Release 配置单独通过。覆盖扫描、暂停/恢复及取消交互、JPEG/PNG 和生成 HEIC 样本预览、HEIC pHash、64-bit pHash、审核排除清单、分类复制恢复与已存在目标重验、备份映射恢复检查点及警告分类、拍摄时间窗口边界、来源变更拒绝、同大小目标改写识别、备份读回与多余文件检查、Final Manifest 过滤、分卷 7z manifest/SHA-256 校验、Windows ExifTool ZIP 完整解包和 UTF-8 参数文件。HEIC 尚未用真实相机样本或干净机器验收。官方 7-Zip 26.05 已通过小卷与大于 2 GB 单文件归档的 `t`，并从大归档提取后核对 SHA-256。

## 构建

macOS arm64 可用 `scripts/build-macos-arm64.sh` 重建。Windows x86_64 可在装有 MinGW-w64 和 Rust GNU target 的开发机上运行 `scripts/build-windows-x86_64.sh`；它输出单个 GUI PE 可执行文件并检查系统导入。两平台的构建都尚未完成干净系统离线运行验收。

请先读 [`docs/implementation-status.md`](docs/implementation-status.md) 和 [`docs/release.md`](docs/release.md)。`target/` 下产物目前仍是开发构建，不是已验收的最终发布包。
