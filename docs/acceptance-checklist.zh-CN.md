## 安装包与启动

- [ ] 从目标提交构建安装包；确认三个 ZIP 文件名都标明版本、平台和架构，并确认 `SHA256SUMS.txt` 与 ZIP 匹配。
- [ ] 在未安装 Rust、Python、Perl、ExifTool、7-Zip、HEIF 扩展或其他运行时的干净断网设备上，解压并启动对应安装包。
- [ ] macOS：从 Finder 启动 `Photo Archive Manager.app`；检查文件选择器、Dock、权限、签名、公证和 Gatekeeper 行为。
- [ ] Windows：启动 GUI 程序，确认可在不额外安装运行时的情况下启动并释放内嵌 ExifTool。
- [ ] 确认首次运行界面为英语；程序运行中切换到中文再切回英语，然后重启并确认所选语言已记住。
- [ ] 确认安装包内含中英双语快速入门、技术文档和第三方声明，且语言跳转链接有效。

## 扫描、整理和校验

- [ ] 同时扫描父目录和子目录；确认文件不会重复计数，且不会跟随符号链接循环。
- [ ] 将 HEIC、MOV 和 JPEG 路由至同一目录，将 RAW 路由至另一目录；确认未映射类型会提示，且同名目标文件不会被覆盖。
- [ ] 确认系统文件的默认排除和重新包含选项；普通隐藏文件及附属文件仍可使用。
- [ ] 比较整理前后的来源文件列表和哈希，确认原件未被修改。
- [ ] 改写一个已复制目标文件的一个字节但保持大小不变；完整性校验必须报告 SHA-256 不匹配。之后恢复内容并重新校验。
- [ ] 在安全边界暂停、恢复、取消并切换阶段；强制退出分类复制或备份后，确认只提供受支持的检查点，并会重新校验已有产物。

## 元数据和重复审核

- [ ] 检查 GPS 和拍摄时间的有效、缺失、不完整、无效、不支持和读取错误状态；有效的 `0,0` 坐标不得仅因坐标为零而被拒绝。
- [ ] 在程序外修改缺失的元数据并完整重检；确认已变化字段标记为 `RESOLVED`，并且依赖结果需要重新检查。
- [ ] 确认一条可读警告；确认显示 `ACCEPTED`，底层字段状态未改变。之后修改文件并确认确认标记消失。
- [ ] 比较可信拍摄时间、时区处理和已知不同相机；不得把文件系统时间当作拍摄时间显示。
- [ ] 确认字节完全相同的文件只会报告而不会删除，视觉候选可供审核并可排除。
- [ ] 使用真实手机和相机 HEIC/HEIF 样本检查方向、预览、感知哈希及 5000 万像素解码限制。
- [ ] 排除一个重复候选后重启程序，确认审核决定恢复，修改后的决定会更新清单。

## 备份和加密归档

- [ ] 将一个来源备份到多个目标；分别复读每个目标并比较 SHA-256。
- [ ] 测试不可写或断开的目标；其他目标结果仍应显示，且已有文件不会被覆盖。
- [ ] 使用确认过的密码创建加密 7z 归档；确认日志和持久检查点都不包含密码。
- [ ] 使用独立安装的 7-Zip 测试归档目录和提取，并确认错误密码无法读取加密文件名或内容。
- [ ] 测试小尺寸分卷、缺卷情况，以及大于 2,000,000,000 字节的文件；比较提取文件和来源的 SHA-256。
- [ ] 执行可选的隔离还原校验；确认提交前会复读还原文件并检查哈希，随后清除临时数据。
- [ ] 中断归档创建后重启；确认恢复时必须重新输入密码并从头重建，且不会覆盖已有产物。

## 平台验收结果

### macOS Apple Silicon 与 Intel

- [ ] 在对应硬件上断网打开正确架构的 `.app`。
- [ ] 完成扫描、元数据、重复审核、备份、加密归档和还原检查。
- [ ] 在 Intel 实机上运行 Intel 安装包；Apple Silicon 上的 Rosetta 检查不能替代此项。
- [ ] 完成签名、公证、Finder、Dock、权限和 Gatekeeper 检查。

### Windows x86_64

- [ ] 在未安装 Perl、ExifTool、7-Zip、HEIF 扩展或其他运行时的干净 Windows 上确认程序可启动。
- [ ] 检查内嵌 ExifTool 的释放、哈希/版本校验、Unicode 和含空格路径，以及常见照片和视频格式的元数据读取。
- [ ] 完成预览、备份、加密分卷创建、独立归档测试和提取检查。
- [ ] 记录 Windows 信任提示和签名状态。
